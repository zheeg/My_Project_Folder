# My_Project_Folde# 🏗️ Construction Schedule Delay Analytics (Month 1: Baseline ML & EDA)

## 📌 Project Overview
This repository is the first deliverable of a 24-week research execution roadmap focused on applying Machine Learning and Computer Vision to Construction Engineering and Management (AEC). 

In **Week 1**, Exploratory Data Analysis (EDA) and domain-specific feature engineering are conducted on the **ConstADEX** construction dataset to identify key drivers of schedule overruns in building projects.
